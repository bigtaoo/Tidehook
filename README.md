# Tidehook

A crane at the end of a pier: cast the hook, haul in fish and treasure, and drag the sea
monsters climbing the dock out of the water before they wreck it. PixiJS 8 + TypeScript.

```bash
npm install
npm run dev     # http://localhost:5190
npm run check   # typecheck, file length, tests, build, bundle size
```

Design docs (Chinese) are in `docs/`; the playable prototype is `prototype/v2.html`.
