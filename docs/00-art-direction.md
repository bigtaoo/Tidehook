## 1. 题材一句话

**《拉钩港》Tidehook**：守在码头尽头的吊钩起重机。往海里甩钩，捞鱼、捞宝藏换钱，也能把爬上岸的海怪拽上来砸碎。
离岸越远，鱼越值钱。海怪越来越凶，码头撑不住就输。

| 原型（v2.html） | 题材 | 说明 |
|---|---|---|
| 钻机 | 码头吊钩起重机 | 玩家本体，固定在近岸端 |
| 金块（小/大） | 鱼 / 宝箱 | 数字 = 重量；离岸越远越值钱 |
| 石头 | 浮木 / 锚 / 破桶 | 甩回去能砸怪 |
| 普通怪 | 螃蟹兵、海胆、章鱼、鮟鱇等 | 从海里往码头爬 |
| 贪吃怪 | 贪吃鲨 | 吃鱼变重；拽上岸被砸死时把吃的鱼吐出来 |
| 炸弹 | 水雷 | 钩到太重的怪时自动引爆 |
| 修理 | 补木板 | 修码头血量 |
| 深矿（vein） | 远洋渔场 | 远处刷出更多更贵的鱼 |
| 串钩 / 磁钩 | 串钩 / 磁铁钩 | 名字不变 |

## 2. 画风：贴纸卡通（沿用 Holy Kicker / Potion Siege）

直接沿用前两个项目已经跑通的风格前缀，不重新探索：

- 粗而均匀的黑色描边，平涂色块，每种颜色只配一档硬朗的 cel 阴影
- 不用渐变、高光、材质纹理，也不做"3D 渲染感"
- 角色约 2 头身（chibi），每只怪都要有**一个独有的剪影特征**（钳子、背鳍、触手、灯笼）
- 判断标准是手机尺寸下看得清，不是大图好看

理由：

1. 两个项目的 Mistral 生图 → `flatten` → `bake_mob` 管线已经验证过，风格前缀拿来就能用。
2. 本作画面元素小且多（海里同时有十几条鱼和怪），粗描边加平涂在小尺寸下最好认。
3. 水体是大面积背景，平涂分层（浅海→深海）既便宜又能直接表达"越远越值钱"。

## 3. 颜色规则

颜色本身就是玩法信息，按角色分配，不允许串用：

| 角色 | 色系 | 例子 |
|---|---|---|
| 玩家 / 码头 / UI | 暖：胡桃木、黄铜、麻绳、奶油纸 | 起重机、码头木板、商店面板 |
| 可捞的收益 | 暖亮：金、橙、珊瑚红 | 金鱼、橙色大鱼、宝箱 |
| 海怪 | 冷：青灰、钢蓝、紫，统一**红眼** | 螃蟹兵、海鳗、海龟、贪吃鲨 |
| 杂物 / 石头 | 中性：褐、灰 | 浮木、锚、破桶 |
| 海水背景 | 冷、降饱和，按距离分层 | 浅滩青绿 → 中海蓝 → 远洋深靛 |
| 危险 / 特效 | 高饱和、少量 | 水雷红、爆炸黄、伤害数字 |

硬规则：

- **怪身上不出现暖色**（红眼除外）。这样暖色就等于"能捞的钱"，一眼可分。这条是 Holy Kicker 和 Potion Siege 的共同教训。
- 鱼可以是海洋生物，但必须暖亮、圆润、表情呆萌；怪必须冷色、有棱角、有敌意。两者剪影要明显不同。
- 海水按离岸距离分 3~4 档明度，作为"价值刻度"。档位边界和 `goldVal` 的距离系数对齐。
- 颜色不能是唯一线索：重量数字始终显示，水雷带图标。
- **抓不动的怪要看得出来**（2026-11-09）。怪的血量超过钩子抓力时，出钩只会把它打掉血、弹开。从第 4 波起，新出的螃蟹兵是 3 血，比初始抓力 2 高，录像里那局有 9 次就这样弹开了，而且看起来和前几波一模一样。现在用两层提示：
  - 血点里超过抓力的那几颗，从奶油色圆点换成钢灰方块，排在最右边。挨打先掉这几颗，掉完就能抓。
  - 抓不动的时候，怪的右上角挂一个钢灰秤砣。血点在手机上只有两三个像素，秤砣才是一眼能看到的信号。

  钢灰 `HEAVY` 是冷色，不破坏"怪身上不出现暖色"；秤砣和方块都靠形状区分，不只靠颜色。买了抓力卡，秤砣和方块会当场消失。
- **投掷要看得见瞄的是谁、打没打中**（2026-11-09）。手里有杂物时，红色瞄准线一直画到会被打中的怪，并给它套一个红圈。这个红圈是界面标记，画在怪外面，不算怪身上的颜色。命中时出宽的黄铜圈，并从怪身上升起"−3"。远处是投掷最常打的地方，奶油色小圈在那里看不出来。
- 海水三档取自 style frame r2（`src/view/kit/palette.ts` 的 `SEA`）：浅滩 `#26B2B0`、中海 `#186E8C`、远洋 `#16284A`。
  螃蟹和海鳗生成出来和中海同色，已用 `recolor.py` 移开：螃蟹改长春花蓝，海鳗改紫。

## 4. 横竖屏构图

只有一套逻辑坐标：**距离（离岸深度）× 宽度**。渲染时按屏幕方向旋转 90°。

- **竖屏**：码头在**屏幕下方**，海往上延伸，怪从上往下爬。
- **横屏**：码头在**屏幕左侧**，海往右延伸，怪从右往左爬。
- 怪和鱼需要两套朝向的图：竖屏用正面/背面，横屏用侧面。做法是先出正面定稿，再用"Redraw the SAME…"编辑出侧面（Potion Siege 的 `enemy_*_side` 做法）。
- 背景分层（码头、浅滩、中海、远洋）做成可平铺的条带，两个方向共用，不画整张背景图。
- 文字和 HUD 不旋转，按方向单独排版（见 [01-tech-plan.md](01-tech-plan.md) 的布局一节）。

## 5. UI 风格

- 用 Pixi Graphics 代码画：圆角面板、粗边、底部"唇边"。调色板沿用 Potion Siege 的胡桃木、黄铜、奶油纸（`view/kit/palette.ts`）。码头题材本身就是木头和黄铜，正好合适。
- 图标走 AI 生成后打成图集（`pack_icons.py`），**不用 emoji**。
- 字体：正文用系统字体，字重 800，加深色描边；Logo 用 Luckiest Guy（OFL）。正文最小 48 设计单位（基于 1080 宽）。
- 文案长度预留约 30%，给德语、俄语等翻译用。

## 6. 美术生产流程

全部沿用 Potion Siege 的 `tools/` 和 prompt 管理方式：

1. **Style frame 先行**：先出一张"实机感"的整屏图，包含起重机、几档海水、3 条鱼、2 只怪、HUD。用户点头后，才开始批量出图。
   生图工具只出 4:3 横图（1024×768 或 1184×880），所以 style frame 按横屏布局画（码头在左，侧栏在右）。prompt 在 `art/prompts/style_frame_gen*.txt`，产物在 `art/style/style_frame_r*.png`。
2. 生图：Mistral agent `image_generation`（`generate_image.sh` / `edit_image.sh` + key 轮换）。
3. 每张图的 prompt 存成 `art/prompts/<name>_gen.txt` 或 `<name>_editN.txt`，和产物同名。
4. 风格锚定：一张通过的样图用文生图，其余全部用"编辑样图"生成，避免风格漂移。
5. 一张图只画一个主体，白底，A-pose 或正视。
6. 后处理（M3 实际管线，`bash tools/build_sprites.sh` 一键重建）：
   - `art/raw/` 存生成器原图（不进包）。脚本里每行写明一个精灵用哪张原图。
   - `flatten.py` 抠图、量化颜色、重描统一描边；`clean_edges.py` 清掉描边旁的杂色点；`recolor.py` 按色相带改色（确定性，正面和侧面改得一样）。产物在 `art/cut/`。
   - `export_web.py` 缩到游戏里最清晰时的尺寸（怪和渔获长边 192 px，够 DPR 3），写进 `art/web/`，同时写 `src/view/artFit.json`（每张图的尺寸和不透明面积折算的半径）。
   - `to_webp.py` 转 WebP q85（alpha 无损）进 `public/art/`，19 张共约 150 kB。
   - 怪的走路不用 `bake_mob.py` 烘帧：`src/view/scene/look.ts` 按走过的距离做起伏和摆动，被眩晕时自然停下。
   - 竖屏怪用正面图（朝下走），横屏用侧面图（朝左走）。
7. **检查**：
   - 每张图都测 alpha，生成器会伪造透明（画出来的棋盘格、半透明残影），这是 Blight Bloom 的教训。
   - 每批图用 `lineup_test.py` 在手机尺寸下并排看。
   - 体型按不透明面积比，不按高度比：视图按 `artFit.json` 把不透明面积缩成命中半径 × 1.5 的圆（`LOOK_SCALE`）。
   - 横跨航道的那一边不超过命中半径 × 2（`ACROSS_MAX`，`look.ts` 的 `lookRadius`）。否则宽图（竖屏的正面乌龟、横躺的原木）看上去碰到了钩子，实际却抓不到。目前只有这两张图被缩小，约缩到原来的 77%。
   - 钩子图的“嘴”（J 形内侧，图高 72% 处）对准模拟里的钩尖，绳子接在顶部的环上（13% 处）。以前环对准钩尖，钩身比判定点向前多伸约 20 个世界单位，钩子看着已经碰到东西，实际还没到。

## 7. 音频

- 全部是本地已有的 CC0 素材：Kenney 的 Impact / Interface / Sci-fi Sounds 和 Music Jingles，音乐用 FreePD 的曲子（见下面“每片海一首”）。不用代码合成音效：Swarm Orbit 记录了 Playgama 审核条款 3.3.2 的风险，Potion Siege 的合成方案不照搬。
- `python tools/build_audio.py` 一键重建：源文件先复制进 `art/audio/sources/`（之后只靠本仓库就能重建），再用 ffmpeg 去头尾静音、限长、转单声道、按 cue 归一峰值，编码成 MP3（各浏览器都能解）写进 `public/audio/<cue>_<n>.mp3`。
  - 音乐做响度归一（-20 LUFS）、保留立体声、64 kbps，去掉头尾静音，避免循环接缝处断一下。
  - **每片海一首，港口一首**（2026-11-10，`public/audio/music_<track>.mp3`，`src/audio/cues.ts` 的 MUSIC）：
    | 场景 | 曲子 | 为什么 |
    |---|---|---|
    | 港口（大厅、标题） | Hopeful（Rafael Krux） | 暖、不急，两局之间喘口气 |
    | 家门口的港湾 | Busybody（Bryan Teoh） | 一开始就用的主题，“快乐地手忙脚乱” |
    | 雾湾 | Managing Mischief（Bryan Teoh），52.5 s 起截 74 s | “调皮又小心”，悄悄地，看不见前面来的是什么 |
    | 风暴海 | Busybody 加快 12%、升两个半音（**不另出文件**，播放时变速） | 同一个港口遇上大风：熟悉的曲子更急 |
  - 都是本地已有的 FreePD 文件（D:/funny 里已经用过、带 CC0 证书），没有从网上下载。只有三首可用，所以风暴海用 Busybody 的变速版而不是第四首曲子；以后有新的 CC0 曲子再换。
  - **风暴海不单独出文件**（2026-11-11）：它就是港湾那首放快 12%，以前却又编码成一份 600 kB 的 `music_storm.mp3`——同一段母带、同一条处理链，只是提前做了变速。现在 `tools/build_audio.py` 的 `SHARED` 跳过它，`src/audio/cues.ts` 的 `musicFile()` 让它指向 `music_bay.mp3`、`musicRate()` 给出 1.12，播放时在 `<audio>` 上设 `playbackRate`（并关掉 `preservesPitch`，这样和 ffmpeg 的 `asetrate` 一样连音高一起升）。包体小了 600 kB，少一次下载，音质反而少了一代转码。浏览器若不支持 `preservesPitch`，只是音高不升、曲子照样更急。
  - 两首共用一个文件时换场景不淡出：直接改 `playbackRate`，曲子不重头来（实际只会从港口切过去，很少碰到）。
  - 换场景时 `<audio>` 只有一个：淡出 0.4 秒、换源、淡入 0.4 秒（iOS 第一次点击解锁的是这个元素，换源不用重新解锁）。截出来的片段两头各淡 0.35 秒，循环接缝是一口气，不是咔哒一声。
  - 同时写 `art/audio/credits.json`（每个文件的来源和授权）、`src/audio/cues.json`（每个 cue 的变体数）和授权原文 `art/audio/licenses/`。

## 8. 已定（2026-11-08）

- **起重机**：胡桃木吊杆 + 黄铜绞盘 + 麻绳，配色和 UI 调色板一致。不做蒸汽吊车，它的铁灰色会和冷色海怪撞色。
  - 游戏里画成**绞车垛**（`winch`）：正面、左右对称、不转动。底下是三层胡桃木垛，中间是缠麻绳的黄铜绞盘，顶上居中一个黄铜滑轮。滑轮中心就是出钩点，在航道正中（`actors.ts` 的 `WINCH_PULLEY` 是滑轮中心在图里的高度比例），绳子和瞄准线都从这里出发。这对应原型里静止、对称的“钻机”。
  - 为什么不用吊杆：
    - 固定斜向右上的吊杆会让玩家顺着吊杆去预判，扔出去的角度看着和预判的不一样。
    - 改成跟着瞄准转的吊杆，手感好了，但整个吊车一直在晃，看着眼花。
    - 吊杆图里的滑轮偏在一侧，出钩点看着往右偏。
  - 来源：`art/prompts/winch_edit1.txt`，在旧吊车图 `crane_e2` 上改出来，风格一致。
- **操作员**：码头老船长只在商店和结算出现（半身像），海面上不画人，战场保持干净。
- **海怪阵营**：杂牌海洋生物，和模拟里的四种怪对应：
  - grunt：螃蟹兵（大钳子）
  - darter：海鳗（细长、快）。它只在水里游：进了航道就不会再游出两侧，碰到码头边缘就算咬到码头，不会像螃蟹那样爬上木板去找吊车。原型里这个位置是蝙蝠，会飞，所以越界在原型里没有问题。
  - brute：海龟（厚壳、血厚）
  - glutton：贪吃鲨（背鳍、大嘴）
  - 全部冷色加红眼，每只靠剪影区分。
- **Style frame**：选定 `art/style/style_frame_r2.png`（三张里最平的一张）作为风格锚点，其余精灵都用"编辑样图"生成。
- **音频**：见第 7 节，全部 CC0，来源记在 `art/audio/credits.json`。

## 9. 改版：海图 + 剪纸（2026-11-09）

第 2 节的贴纸卡通（粗黑描边、平涂、表情夸张）是 AI 生图最常见的样子，测试者说"一看就是 AI 做的"。试了七个方向（`art/style/style_frame_r4`–`r10`：丝网印、版画、扁平、剪纸、古海图、像素、水粉），选了两个拼起来：

- **海和岸：古海图**（r8）。米黄纸底，水彩青绿到深蓝，淡淡的等深线；码头是钢笔线描的木栈桥，缠绳的木桩。
- **怪、鱼、杂物、人物：剪纸**（r7）。哑光卡纸，剪刀剪出的不太齐的边，看得见纸纤维，几层纸叠出厚度；**没有描边**。
- 拼接试样：`style_frame_r14_mix_land.png`（横屏）、`r16_mix_port_cold.png`（竖屏冷色），用户选定。

规则（替换第 2 节，第 3 节的颜色规则照旧）：

- 怪一律冷色：螃蟹长春花蓝、海鳗紫、海龟石板灰蓝、鲨鱼灰紫。不再用红眼（红眼是旧风格的"凶"），怪和鱼都是**黑色小圆点眼**，没有眉毛、牙齿、嘴和笑脸。敌意靠颜色和剪影，不靠表情。
- 鱼和宝箱是暖色（金、橙、珊瑚），杂物褐灰。船长也是剪纸，平静站着，不比大拇指。
- 精灵的影子在代码里画（`sprites.ts`）：同一张图染成深蓝、32% 透明，往右下偏移面积半径的 0.12 / 0.2。光一直从屏幕左上来，不随航道转。剪纸贴在纸上的那种投影。
- 背景是一整张图（`public/art/sea.webp`），不再是代码画的色带。码头在图的左边，竖屏时向左转 90°，码头到底下。海水由浅到深本来就是价值刻度；两条价格分界画成海图的虚线等深线（`field.ts`）。
- UI：去掉亮绿按钮，"下一波""出海"用海图青 `P.go`。

生产：

- 风格锚点是 `art/raw/mix/crab.png`（从 r7 里单独剪出的螃蟹），19 张精灵都是编辑它得来的，prompt 在 `art/prompts/<name>_paper_edit1.txt`。
- `tools/paper.py` 只抠图、往里收 1 像素、缩放；不重描边、不量化颜色，纸的纹理就是风格。`flatten.py`、`clean_edges.py`、`recolor.py` 留给旧图。
- 背景：`art/raw/mix/bg.png`（从 r8 去掉所有生物）→ 编辑去掉绞车、边框和罗盘（`mix_bg_edit2.txt`）→ `tools/build_sea.py` 把码头那一条缩到航道的码头宽度（112/800），海缩到其余部分，输出 1600×960。

现状（2026-11-10）：

- 25 张精灵全部是剪纸新图（19 张原有 + 寄居蟹、鳐鱼、大章鱼的正面和侧面），旧的粗描边卡通一张不剩。海图背景、代码影子都在。竖屏、横屏在浏览器里看过，三条海色带上都读得清。
- 新怪接替了替身：`artFit.json` 里有了名字，`look.ts` 就用真图。
- 鱼钩比例：钩口在高度 0.8，钩环 0.09；绞盘滑轮中心在高度 0.142（`actors.ts` 的 `WINCH_PULLEY`）。
- 屏幕底色 `SEA.deep` 改成背景远海的深蓝 0x082040。

生成出来不合格时怎么办（`build_sprites.sh` 的 `PICK` 逐张写了原因）：

- **像照片或 3D 渲染**（木桶、水雷、绞盘第一版）：重写 prompt，明说"FLAT paper""children's paper collage""no 3D render, no real wood, no gloss"。但只说平面又会太空（绞盘第二版只剩几个色块），要同时点名有多少层纸、几条纸带、几个纸方块，见 `winch_paper_edit3.txt`。
- **怪带了暖色**（寄居蟹红钳、大章鱼粉吸盘、宝箱柠檬黄）：不重画，用 `tools/recolor.py` 换色相；它只动饱和度 >0.15 的像素，淡粉色要另写掩码。
- **有眼白、嘴或笑脸**（寄居蟹侧面、大章鱼侧面、鲨鱼正面）：用圆形掩码把眼白填成黑点、用身体颜色抹掉嘴。方形掩码会把旁边的白底也涂黑。
- **怪在浅水上看不清**（寄居蟹的青绿壳）：把壳降饱和、往蓝灰偏。锚太暗沉进深海：提亮。
- **抠图**：白胡子、鲨鱼米色肚子和白底之间没有边，`paper.py` 对它们只把接近纯白（≥249）的当背景。闭合的圈（盘起来的海鳗、绞盘滑轮的辐条之间）用 `HOLES` 另外清掉圈里的白底，每张图各有面积下限和灰度上限：海鳗不限颜色（圈内侧的淡紫纸也要去掉），绞盘只清灰白，奶油色绳带要留着。
